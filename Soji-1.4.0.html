Soji 1.4

Soji habla inglés, funciona con VoiceOver y puede abrirse al iniciar sesión.

Novedades

  • Soji en inglés: toda la app está traducida. Se muestra en inglés en un Mac en inglés (y en cualquier idioma que no sea el español).
  • Abrir Soji al iniciar sesión (Ajustes → General): Soji arranca en la barra de menús sin poner la ventana delante.
  • VoiceOver: el Mapa del disco se recorre bloque a bloque, el gráfico de tipos se lee como resumen, cada fila es un solo elemento con sus acciones y el estado del disco se lee como una frase.
  • Microsoft Edge y Brave en Privacidad y navegadores, con caché, historial y cookies por perfil.
  • Una fila por versión de Node (nvm), Rust (rustup) y Python (pyenv) en Otras áreas grandes, con su tamaño y el comando exacto para quitarla.
  • Ayuda → Exportar diagnóstico…: un informe de texto, revisable antes de enviarlo, para pedir soporte.

Corregido

  • El comando sugerido para quitar una imagen de Docker sin etiqueta usa su ID.
  • Los ajustes de antigüedad mostraban un marcado extraño en vez de «30 días».
  • Concordancias en español («3 elementos seguros», «cada minuto»…).
  • Al analizar otra carpeta en el Mapa del disco, la ruta muestra su nombre en vez de «Inicio».

Soji 1.4

Soji now speaks English, works with VoiceOver and can open at login.

What’s new

  • Soji in English: the whole app is translated. It shows in English on a Mac set to English (or to any language other than Spanish).
  • Open Soji at login (Settings → General): Soji starts in the menu bar without bringing its window to the front.
  • VoiceOver: the Disk Map can be explored block by block, the file-type chart reads as a summary, each row is a single element with its actions, and disk status reads as one sentence.
  • Microsoft Edge and Brave in Privacy & Browsers, with cache, history and cookies per profile.
  • One row per version of Node (nvm), Rust (rustup) and Python (pyenv) in Other Large Areas, with its size and the exact command to remove it.
  • Help → Export Diagnostics…: a text report, reviewable before sending, for support requests.

Fixed

  • The suggested command to remove an untagged Docker image now uses its ID.
  • The age settings showed odd markup instead of “30 days”.
  • When scanning another folder in the Disk Map, the path shows its name instead of “Home”.
