# Soji — Releases

Binarios firmados y notarizados de **Soji** y el *appcast* de
[Sparkle](https://sparkle-project.org) para la auto-actualización.

- **Appcast:** <https://tavodev.github.io/soji-releases/appcast.xml>
- **Descargas:** pestaña [Releases](https://github.com/tavodev/soji-releases/releases)

El código fuente de Soji es **privado**; este repositorio solo aloja los artefactos públicos
que necesita el actualizador. Lo gestiona `make release` desde el repo principal: no edites el
`appcast.xml` a mano.
